# 구독 사용량 조회 계획 — 구현 보류

2026-11-03 사용자 요청으로 계획만 기록한다. 사용량 조회 버튼, 조회 API,
통계 수집은 이번 변경에 구현하지 않는다. 다음 작업에서 이 문서부터 이어간다.

## 원하는 화면

메인 대화 입력창 하단의 **Workspace Write 바로 오른쪽**에 작은 **사용량**
버튼을 둔다. 로그인 카드에 붙이지 않는다. 버튼을 누르면 Codex와 Gemini를
함께 보여주는 팝오버가 열린다. 화면 바깥 클릭이나 Escape로 닫히며,
새로고침 버튼, 마지막 조회 시각, 로딩·실패 상태를 각 공급자별로 표시한다.
조회 실패를 잔여량 0%로 표시하지 않고, 다른 공급자의 정상 결과는 유지한다.
모바일에서도 화면을 넘치지 않게 배치한다.

## 표시할 데이터

### Codex

기존 구독 OAuth 로그인을 재사용한다. OpenAI API 결제 잔액과 혼동하지 않는다.
현재 계정에서 `https://chatgpt.com/backend-api/wham/usage` 읽기 조회가 성공했다.
응답의 `rate_limit.primary_window`와 `secondary_window`에는 `used_percent`,
`limit_window_seconds`, `reset_at`, `reset_after_seconds`가 있었다. 창의 길이는
응답을 기준으로 표시하고, 고정된 요금제별 한도를 가정하지 않는다.
`additional_rate_limits`는 null일 수 있다. 선택적으로 모델별 추가 창을 표시한다.
정확한 사용자 ID, 계정 ID, 이메일, 토큰은 UI로 전송하지 않는다.

토큰 갱신은 모델 연결 플러그인의 인증 수명주기에 맡긴다. 복사한 refresh token을
별도로 갱신하지 않는다. 장시간 열린 팝오버의 갱신 간격과 서버 캐시는 다음
구현에서 정하고, 무한 재시도나 한도 초기화 기능은 추가하지 않는다.

### Gemini Web

현재 브릿지는 웹 로그인 프로필을 사용한다. 실제 잔여 할당량을 웹에서 안정적으로
조회할 수 있는지 먼저 확인한다. 확인되지 않으면 **잔여 한도 조회 미지원**으로
표시한다. 브릿지의 요청 수·문자 기반 토큰 추정치를 실제 구독 잔여 한도나
정확한 사용률로 바꾸어 표시하지 않는다.

원하면 브릿지를 통해 관측한 요청 수와 토큰 추정치를 별도 **이 환경의 사용 기록**
영역에 표시할 수 있다. Google 웹·앱에서 직접 사용한 양은 포함되지 않음을 밝힌다.
이 로컬 통계 수집도 현재는 구현하지 않는다.

## 기존 플러그인 후보와 미결정 사항

- [WSL043/dsh-codex-subscription](https://github.com/WSL043/dsh-codex-subscription):
  Codex 로그인·모델·구독 한도·사용 기록을 통합한다. 현재 DSH 0.2.1-rc.2 지원을
  문서에 명시한다. Codex 연결을 이 플러그인으로 교체할지는 별도 결정한다.
- [Han-1413141/dsh-cost-meter](https://github.com/Han-1413141/dsh-cost-meter):
  토큰·비용·지원되는 Codex 구독 한도를 제공한다. 현재 자체 fork의 인증 형식 및
  원하는 버튼 위치와 호환되는지 확인해야 한다.
- [xinglan163/dsh-gemini-quota](https://github.com/xinglan163/dsh-gemini-quota):
  Gemini 웹 한도 표시 기능이 있지만 gemini-web2api-go 백엔드를 대상으로 한다.
  현재 Playwright 브릿지에 그대로 연결할 수 있다고 가정하지 않는다.

Codex 교체와 사용량 UI를 하나의 필수 마이그레이션으로 묶지 않는다. 기존 로그인을
안전하게 이전할 수 있는지, 기본으로 켜지는 다른 기능이 있는지 먼저 확인한다.

## 구현 순서

1. 모델 연결 플러그인과 구독 상태 데이터의 소유자를 확정한다.
2. DSH의 공식 입력창 확장 슬롯을 확인하고, Workspace Write 오른쪽에 버튼과
   접근 가능한 팝오버를 구현한다. 기존 권한 선택 기능을 덮어쓰지 않는다.
3. 서버에서만 구독 한도를 조회하고 표시용 수치·초기화 시각만 반환한다.
   기존 DSH 인증과 동일 출처 보호를 적용한다.
4. 각 공급자의 로딩·성공·미지원·로그인 만료·일시적 실패를 구분한다.
5. 실제 계정 응답과 대조하고 저장소에 커밋·push한 뒤 고정 커밋으로 배포한다.

## 완료 조건

- 버튼이 실제 Workspace Write 오른쪽에 있고 작은 화면에서도 사용할 수 있다.
- 클릭해서만 팝오버가 열리며 키보드, Escape, 바깥 클릭이 작동한다.
- 서버가 제공한 사용률·창 길이·초기화 시각과 화면이 일치한다.
- 누락된 창, null 응답, 로그인 만료, 네트워크 실패를 다루며 이전 실패 표시가
  성공 후 남지 않는다.
- Gemini 실제 할당량과 로컬 관측치를 분리한다. 토큰이나 인증 코드를 반환·기록하지 않는다.
